# CHECKLIST.md — 최종 검증 체크리스트

`docs/PRD.md`의 요구사항(F-xx / NF-xx)을 **실제로 실행해서 확인할 수 있는 행동**으로 옮긴 것이다.
`docs/ROADMAP.md` 3장 "완료 판정" 칼럼이 이 문서의 **항목 번호**를 인용하므로, **번호를 바꾸면 ROADMAP도 함께 고친다.**

---

## 0. 사용법

- 각 항목은 **"이 조작을 하면 이 결과가 나온다"** 형태다. "구현했다"는 완료가 아니다.
- `☐` → 미검증, `✅` → 통과, `❌` → 실패(사유 기록), `⏭` → 해당 Phase 아직 미착수.
- **한 Phase를 끝냈다고 선언하기 전에, ROADMAP이 그 Phase에 지정한 항목을 실제로 실행한다.**
- 검증 도구: 백엔드는 Swagger UI(`/swagger-ui/index.html`) 또는 curl, DB는 psql, 프론트는 브라우저 + DevTools.
- `{{TOKEN}}`, `{{ID}}` 등은 실행 시점의 실제 값으로 치환한다.
